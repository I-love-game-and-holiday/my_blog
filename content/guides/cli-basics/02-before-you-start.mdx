## 記事のコマンド表記について

技術記事やドキュメントでは、コマンドの前に `$` や `>` が付いていることがあります。

```bash
$ npm install
$ git status
```

この `$` は「ここからコマンドを入力してください」という**目印**です。<br />
実際に入力するときは `$` を含めず、`npm install` だけを入力します。

Zenn や Qiita などの技術記事で `$ npm install` と書いてあったら、`npm install` だけをコピーして実行しましょう!

## 組み込みコマンドと外部コマンド

CLI で使えるコマンドには、大きく分けて 2 種類あります。

### 組み込みコマンド（最初から使える）

OS やシェルに最初から入っているコマンドです。<br />
前のセクションで紹介した`pwd`や `cd`、`ls`、 などがこれにあたります。

```bash
cd Documents    # 最初から使える
ls              # 最初から使える
pwd             # 最初から使える
```

### 外部コマンド（インストールが必要）

別途インストールしないと使えないコマンドです。<br />
開発でよく使うツールの多くはこちらに該当します。

### コマンドが見つからないとき

インストールしていないコマンドを実行すると、エラーになります。

```bash
$ aws --version
# bash: aws: command not found
# （awsコマンドがインストールされていない）
```

このエラーが出たら、そのコマンドをインストールする必要があります。<br />
「○○ インストール 方法」で検索してみましょう。

## ローカル環境の注意点

CLI で実行するコマンドは、**あなたの PC にインストールされているバージョン**を使います。

これは当たり前のようで、初心者がつまずきやすいポイントです。

### バージョン確認の習慣

問題が起きたら、まずバージョンを確認しましょう。

```bash
node --version    # Node.js のバージョン
# v20.10.0

npm --version     # npm のバージョン
# 10.2.3

git --version     # Git のバージョン
# git version 2.43.0
```

記事やドキュメントに「Node.js 18 以上が必要」と書いてあったら、自分の環境が条件を満たしているか確認してください。

### バージョンが違うときは

バージョンが古い場合は、アップデートが必要です。

- **Node.js**: nvm や volta などのバージョン管理ツールを使うと便利
- **その他**: 各ツールの公式サイトでアップデート方法を確認

<small>※バージョン管理ツールについては、別のガイドで詳しく解説予定です。</small>
