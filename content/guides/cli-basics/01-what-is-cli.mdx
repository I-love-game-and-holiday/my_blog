## CLI とは

**CLI（Command Line Interface）** は、テキストベースでコンピュータを操作するインターフェースです。

普段使っているマウスやタッチで操作する画面は **GUI（Graphical User Interface）** と呼ばれます。<br />
例えば、Yahoo のホームページはマウスで検索ボタンをクリックしたり、ニュースのリンクをクリックすることで記事の詳細ページへ遷移したりしますよね。

一方、CLI はキーボードでコマンド（命令文）を入力して操作します。<br />
映画で悪役が黒い画面を見ながらキーボードカタカタしてるやつです。<br />
例えば、PowerShell（後述）で **pwd** と叩いてみるとパスが表示されます

## なぜ CLI を学ぶのか

エンジニアのお仕事では、CLI の知識が必須です。<br />
このサイトを例に、どこで CLI を使っているか見てみましょう。

### 1. 環境構築

僕は WindowsPC でこのサイトを作りました。このサイトは TypeScript で作られています。<br />
TypeScript を動かすには Node.js が必要ですが、Windows には最初から入っていません。

CLI で `winget install nodejs` と入力してインストールします。

```bash
winget install nodejs
```

### 2. ライブラリのインストール

開発に必要なライブラリ(便利グッズみたいなもの)も CLI でインストールします。(これがないと開発ができない)

```bash
npm install
```

### 3. コードの管理

作成したコードは GitHub で管理します。<br />
コードのアップロードも CLI で行います。

```bash
git push
```

このように、環境構築からコード管理まで、開発のあらゆる場面で CLI を使います。

<small>
  ※データベースの操作、クラウド(AWS など)の構築・運用など、他にも多くの場面で
  CLI を使います。
</small>

## ターミナルとシェル

「CLI を使いたい！」となったとき、何を起動すればいいのでしょうか？<br />
ここで登場するのが **ターミナル** と **シェル** です。

### ターミナルとは

**ターミナル**（端末）は、CLI を使うための「窓口」となるアプリです。<br />
黒い画面（または白い画面）が表示されて、そこにコマンドを入力します。

身近なもので例えると、**テレビのようなもの**です。<br />
テレビは映像を映し出す「箱」であり、中身の番組（コンテンツ）は放送局が作っています。<br />
ターミナルも同じで、画面を表示する「箱」であり、中身の処理は別のプログラムが担当しています。

Microsoft Store から無料でインストールできます。

### シェルとは

**シェル** は、ターミナルの中で動いている「通訳プログラム」です。<br />
あなたが入力したコマンドを理解して、コンピュータに伝えてくれます。

先ほどのテレビの例で言うと、**放送局のようなもの**です。<br />
テレビ（ターミナル）に映し出される番組（処理結果）を作っているのがシェルです。

### ターミナルとシェルの関係

まとめると、こんな関係になっています。

  outer={{ label: "ターミナル（箱）", description: "画面を表示するアプリ" }}

**ポイント**: 同じターミナルでも、中で動くシェルを変えることができます。<br />
例えば、Windows Terminal で bash を動かすこともできます（WSL を使う場合など）。

最初は「ターミナル = シェル」と思っていても大丈夫です。
