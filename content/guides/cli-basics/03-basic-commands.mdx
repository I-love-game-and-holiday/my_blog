## ディレクトリ操作

### 現在地を確認する: pwd / Get-Location

現在いるディレクトリのパスを表示します。

<OsCodeBlock
  mac={`pwd
# 出力例: /Users/tanaka/projects`}
  windows={`pwd
# または
Get-Location
# 出力例: C:\\Users\\tanaka\\projects`}
  title="現在のディレクトリを表示"
/>

### ファイル一覧を見る: ls / Get-ChildItem

ディレクトリ内のファイルとフォルダを一覧表示します。

<OsCodeBlock
  mac={`ls
# 出力例: Documents  Downloads  Pictures

ls -la # 隠しファイルも含めて詳細表示`}
  windows={`ls

# または

Get-ChildItem

# 出力例: Documents Downloads Pictures

ls -Force # 隠しファイルも含めて表示`}
title="ファイル一覧を表示"
/>

### ディレクトリを移動する: cd

作業ディレクトリを変更します。

<OsCodeBlock
  mac={`cd Documents      # Documentsに移動
cd ..             # 1つ上のディレクトリに移動
cd ~              # ホームディレクトリに移動
cd /              # ルートディレクトリに移動`}
  windows={`cd Documents      # Documentsに移動
cd ..             # 1つ上のディレクトリに移動
cd ~              # ホームディレクトリに移動
cd \\              # ルートディレクトリに移動`}
  title="ディレクトリを移動"
/>

## ファイル操作

### ファイルをコピー: cp / Copy-Item

<OsCodeBlock
  mac={`cp original.txt copy.txt           # ファイルをコピー
cp -r folder1 folder2              # フォルダを再帰的にコピー`}
  windows={`cp original.txt copy.txt           # ファイルをコピー
# または
Copy-Item original.txt copy.txt

cp -Recurse folder1 folder2 # フォルダを再帰的にコピー`}
title="ファイル/フォルダをコピー"
/>

### ファイルを移動/リネーム: mv / Move-Item

<OsCodeBlock
  mac={`mv old.txt new.txt                 # リネーム
mv file.txt Documents/             # 移動`}
  windows={`mv old.txt new.txt                 # リネーム
# または
Move-Item old.txt new.txt

mv file.txt Documents/ # 移動`}
title="ファイルを移動/リネーム"
/>

### ファイル/フォルダを削除: rm / Remove-Item

<OsCodeBlock
  mac={`rm file.txt                        # ファイル削除
rm -r folder                       # フォルダを再帰的に削除`}
  windows={`rm file.txt                        # ファイル削除
# または
Remove-Item file.txt

rm -Recurse folder # フォルダを再帰的に削除`}
title="ファイル/フォルダを削除"
/>

**注意**: `rm` は取り消しできません。ゴミ箱に入らず完全に削除されます。

## ディレクトリ作成

### mkdir / New-Item

<OsCodeBlock
  mac={`mkdir new-folder                   # フォルダ作成
mkdir -p path/to/deep/folder       # 深い階層も一度に作成`}
  windows={`mkdir new-folder                   # フォルダ作成
# または
New-Item -ItemType Directory -Name new-folder

mkdir -p path\\to\\deep\\folder # 深い階層も一度に作成`}
title="ディレクトリを作成"
/>
