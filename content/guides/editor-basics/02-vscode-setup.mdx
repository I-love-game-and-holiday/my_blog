## VSCode のインストール

### Windows の場合

1. [VSCode公式サイト](https://code.visualstudio.com/) にアクセス
2. 「Download for Windows」をクリック
3. ダウンロードしたインストーラーを実行
4. 指示に従ってインストール（基本的に「次へ」でOK）

{/* TODO: ダウンロードページの画像 */}

<Callout type="tip">
**インストール時のオプション**

「PATHへの追加」にチェックを入れておくと、ターミナルから `code` コマンドでVSCodeを起動できるようになります。
</Callout>

### Mac の場合

1. [VSCode公式サイト](https://code.visualstudio.com/) にアクセス
2. 「Download for Mac」をクリック
3. ダウンロードした `.zip` ファイルを展開
4. 展開された「Visual Studio Code.app」をアプリケーションフォルダに移動

または、Homebrew を使う場合：

```bash
brew install --cask visual-studio-code
```

## 日本語化

VSCode はデフォルトで英語表示ですが、日本語化できます。

1. VSCode を起動
2. `Ctrl + Shift + X`（Mac: `Cmd + Shift + X`）で拡張機能パネルを開く
3. 検索欄に「Japanese」と入力
4. 「Japanese Language Pack for Visual Studio Code」をインストール
5. VSCode を再起動

<Callout type="info">

技術ドキュメントは英語が多いので、英語に慣れておくと後々楽です。
最初は日本語化して、慣れてきたら英語に戻すのもアリです。
</Callout>

## フォルダを開く

VSCode では「フォルダを開く」ことでプロジェクトを管理します。

### 方法1: メニューから開く

1. メニューバーの「ファイル」→「フォルダーを開く」
2. 作業したいフォルダを選択
3. 「フォルダーの選択」をクリック

### 方法2: ターミナルから開く

作業したいフォルダで以下のコマンドを実行：

```bash
code .
```

`.` は「現在のディレクトリ」を意味するので、今いる場所をVSCodeで開きます。

<Callout type="tip">
**プロジェクトのルートフォルダを開く**

個別のファイルではなく、プロジェクト全体のフォルダを開くようにしましょう。
そうすることで、ファイル間の移動や検索がスムーズになります。
</Callout>

## 基本的な設定

### 設定画面を開く

- Windows: `Ctrl + ,`
- Mac: `Cmd + ,`

または、メニューバーの「ファイル」→「ユーザー設定」→「設定」
