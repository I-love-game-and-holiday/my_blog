## VSCodeをダウンロード

下記リンクから、お使いのOSに合ったインストーラーをダウンロードしてください。

<a href="https://code.visualstudio.com/" target="_blank" rel="noopener noreferrer">VSCode公式サイト</a>

ダウンロードしたファイルを実行し、画面の指示に従ってインストールすれば完了です。

<Callout type="info">
**Macをお使いの方へ**

初回起動時に「開発元が未確認」という警告が出る場合があります。<br />
その場合は「システム設定」→「プライバシーとセキュリティ」から許可してください。
</Callout>

## 日本語化する

VSCodeは初期状態では英語表示です。日本語で使いたい場合は、拡張機能をインストールしましょう。

1. VSCodeを起動
2. 左側の四角いアイコン（拡張機能）をクリック
3. 検索欄に「Japanese」と入力
4. 「Japanese Language Pack for Visual Studio Code」をインストール
5. VSCodeを再起動

<Callout type="info">
**日本語化の是非について**

僕は日本語化をお勧めします。母国語が一番楽です。<br />
極まれにエディタが壊れて初期化する必要があったり、半年前の設定を再編集することもあります。
慣れない操作を慣れない言語で作業するのは結構ストレスです。
</Callout>

## ショートカットやコマンドについて

VSCodeには便利なショートカットやコマンドがたくさんありますが、最初から全部覚える必要はありません。

**使っていく中で「これ面倒だな」と思ったら、その都度調べて覚えていけばOKです。**

よく使う操作は自然と身についていきます。
