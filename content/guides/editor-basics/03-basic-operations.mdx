## エディターの基本操作

このセクションではよく使うショートカットをまとめています。

## ファイル操作

### 新規ファイル作成

- ショートカット: `Ctrl + N`（Mac: `Cmd + N`）
- または、エクスプローラーでフォルダを右クリック →「新しいファイル」

### ファイルを開く

- ショートカット: `Ctrl + O`（Mac: `Cmd + O`）
- または、エクスプローラーでファイルをクリック


### ファイルを保存

- 保存: `Ctrl + S`（Mac: `Cmd + S`）
- 名前を付けて保存: `Ctrl + Shift + S`（Mac: `Cmd + Shift + S`）
- すべて保存: `Ctrl + K` → `S`（Mac: `Cmd + K` → `S`）

### ファイルを閉じる

- 現在のタブを閉じる: `Ctrl + W`（Mac: `Cmd + W`）
- すべてのタブを閉じる: `Ctrl + K` → `W`

## 検索と置換

### ファイル内検索

- 検索: `Ctrl + F`（Mac: `Cmd + F`）
- 置換: `Ctrl + H`（Mac: `Cmd + H`）

### プロジェクト全体検索

- 検索: `Ctrl + Shift + F`（Mac: `Cmd + Shift + F`）
- 置換: `Ctrl + Shift + H`（Mac: `Cmd + Shift + H`）

<Callout type="tip">
**検索オプション**

検索ボックスの右側にあるアイコンで、以下のオプションを切り替えられます：
- `Aa` : 大文字・小文字を区別
- `Ab` : 単語単位で検索
- `.*` : 正規表現を使用
</Callout>

### 定義へ移動

関数や変数の定義元にジャンプできます。

- `F12` : 定義へ移動
- `Alt + F12`（Mac: `Option + F12`）: 定義をプレビュー表示
- `Ctrl + クリック`（Mac: `Cmd + クリック`）: 定義へ移動

## 統合ターミナル

VSCode 内でターミナル（CLI）を使えます。

### ターミナルを開く

- ショートカット: `` Ctrl + ` ``（バッククォート）
- または、メニューバーの「表示」→「ターミナル」

### 複数のターミナル

- 新しいターミナルを追加: `Ctrl + Shift + `` ` ``
- ターミナルを切り替え: ターミナルパネル右上のドロップダウン

<Callout type="info">
**ターミナルの種類を選べる**

Windows の場合、PowerShell、コマンドプロンプト、Git Bash などから選択できます。
ターミナルパネル右上の「+」の横にある「∨」から選べます。
</Callout>

## コマンドパレット

VSCode の全機能にアクセスできる万能ツールです。

- ショートカット: `Ctrl + Shift + P`（Mac: `Cmd + Shift + P`）

やりたいことを入力すると、関連するコマンドが表示されます。

```
例: 「format」と入力 → 「Format Document」が表示される
```

ショートカットを覚えていなくても、コマンドパレットから何でも実行できます。
