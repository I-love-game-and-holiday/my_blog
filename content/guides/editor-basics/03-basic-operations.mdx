## コマンドパレット

VSCode の全機能にアクセスできる万能ツールです。

- ショートカット: `Ctrl + Shift + P`（Mac: `Cmd + Shift + P`）

やりたいことを入力すると、関連するコマンドが表示されます。

```
例: 「format」と入力 → 「Format Document」が表示される
```

ショートカットを覚えていなくても、コマンドパレットから何でも実行できます。
