## スニペット

よく使うコードパターンを短いキーワードで展開できます。

### 組み込みスニペット

例えば、HTML ファイルで `!` と入力して `Tab` を押すと：

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>

</body>
</html>
```

このようなHTMLの雛形が一発で展開されます。

### Emmet

HTML/CSS を高速に書ける記法です。VSCode には標準で組み込まれています。

```
div.container>ul>li*3

↓ Tab を押すと展開

<div class="container">
  <ul>
    <li></li>
    <li></li>
    <li></li>
  </ul>
</div>
```

## 分割エディター

複数のファイルを並べて表示できます。

- `Ctrl + \`（Mac: `Cmd + \`）: エディターを分割
- ファイルタブをドラッグして分割エリアにドロップ

## 設定の同期

複数のPCで同じ設定を使いたい場合、設定の同期機能が便利です。

1. 左下の歯車アイコン →「設定の同期をオンにする」
2. GitHub または Microsoft アカウントでサインイン
3. 同期する項目を選択

同期できる項目：
- 設定
- キーボードショートカット
- 拡張機能
- ユーザースニペット
- UI の状態

## ワークスペース

プロジェクトごとの設定を保存できます。

### ワークスペース設定

プロジェクトフォルダ内に `.vscode/settings.json` を作成すると、そのプロジェクト専用の設定になります。

```json
// .vscode/settings.json
{
  "editor.tabSize": 4,
  "editor.formatOnSave": true
}
```

### マルチルートワークスペース

複数のフォルダを1つのワークスペースとして開けます。
関連する複数のプロジェクトを同時に扱うときに便利です。
