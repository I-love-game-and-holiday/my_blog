## リモートで履歴を管理するには

今まで紹介したGitのコマンドはあくまで自分のパソコン内で利用するバージョン管理システムです。

このGitをベースにした、ホスティングサービスが複数あります。

その代表が **GitHub** です。

<Callout>
ここでいうホスティングサービスとは **他の人とファイルの変更を共有できるサービス** という意味で理解してOKです
</Callout>
## ローカルとリモート

Git を使った開発では、**2つの場所** にリポジトリが存在します。

    ["場所", "自分のPC", "GitHub（インターネット上）"],

  ]}
/>


<ContentImage

/>

今まで行っていた、コミットはローカル（自分のPC）で行われていました。これは以下のような状況です。

- パソコンが壊れたらその変更履歴はどこにも残らない
- 他の人は変更内容を知ることができない

Githubではローカルの履歴をリモートに送るために **push**,リモートから取り込むために **pull** を利用します。


### push
ローカルの変更をリモートに送る（アップロード）
<FlowDiagram
  steps={[
    "ローカルで編集・コミット",
    "git push（アップロード）",
    "GitHub（リモート）",
  ]}
/>

### pull
リモートの変更をローカルに取り込む（ダウンロード）
<FlowDiagram
  steps={[
    "GitHub（リモート）",
    "git pull（ダウンロード）",
    "ローカルに反映",
  ]}
/>

GitHubへ変更をプッシュしたなら以下のような状況になります

- 自分のパソコンが壊れても変更が保存される
- 他の人が変更内容を取得することができる
