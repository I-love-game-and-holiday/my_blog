## Git ≠ GitHub

まず大事なことを確認しましょう。**Git と GitHub は別物です。**

  headers={["", "Git", "GitHub"]}
  rows={[
    ["何か", "バージョン管理ツール", "Git リポジトリのホスティングサービス"],
    ["どこで動く", "自分のPC（ローカル）", "インターネット上（クラウド）"],
    ["誰が作った", "Linus Torvalds", "GitHub, Inc.（現 Microsoft）"],
    ["料金", "無料", "基本無料（有料プランあり）"],
  ]}
/>

簡単に言うと、Git は「変更履歴を管理するツール」で、GitHub は「Git のデータをインターネット上で保管・共有できるサービス」です。

Google ドキュメントに例えると、こうなります。

- **Git** = 文書の編集履歴を管理する仕組み
- **GitHub** = Google ドライブ（保管場所 + 共有機能）

## ローカルとリモート

Git を使った開発では、**2つの場所** にリポジトリが存在します。

### push と pull

ローカルとリモートの間でデータをやり取りするコマンドが **push** と **pull** です。

<FlowDiagram
  steps={[
    "ローカルで編集・コミット",
    "git push（アップロード）",
    "GitHub（リモート）",
  ]}
/>

<FlowDiagram
  steps={[
    "GitHub（リモート）",
    "git pull（ダウンロード）",
    "ローカルに反映",
  ]}
/>

- **push**: ローカルの変更をリモートに送る（アップロード）
- **pull**: リモートの変更をローカルに取り込む（ダウンロード）

## なぜ GitHub を使うのか

1. **バックアップ**: PCが壊れてもコードが残る
2. **共有**: チームメンバーとコードを共有できる
3. **レビュー**: プルリクエストでコードレビューができる
4. **公開**: 自分の作品をポートフォリオとして公開できる
