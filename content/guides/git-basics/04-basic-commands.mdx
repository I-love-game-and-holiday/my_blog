## 基本コマンドの全体像

Git の基本コマンドは、大きく分けて **3つの場面** で使います。

1. **リポジトリの準備**
2. **変更の記録**
3. **履歴の確認**

覚えなくて大丈夫です。[Learn: Git を使ってみよう](/learn/git-hands-on) で実際に手を動かして覚えましょう。

## 履歴の確認

<ContentTable
  headers={["コマンド", "何をするか"]}
  rows={[
    ["git status", "現在の状態を確認する（変更があるか、ステージに何があるか）"],
    ["git log", "コミット履歴を一覧で見る"],

  ]}
/>

<Callout type="info">
**`git status` は最も使うコマンドです。** 迷ったらまず `git status` を打ちましょう。今何が起きているかを教えてくれます。
</Callout>
