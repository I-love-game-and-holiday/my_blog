## Node.js とは

**Node.js**(ノードジェーエス) は、JavaScriptの実行環境の一つです。

JavaScriptは元々ブラウザ（ChromeやEdgeなど）の中でしか動かせない言語でした。<br />
Node.jsがあれば、ブラウザがなくてもJavaScriptを実行できます。

## Node.js の特徴

### 1. パッケージ管理ができる

Node.jsをインストールすると、**npm（Node Package Manager）** というツールが一緒についてきます。<br/>
npmを使うと、世界中の開発者が作った便利アイテム（ライブラリ等）を簡単にインストールできます。

<Callout>
**他の実行環境にもパッケージ管理はある**

JavaScript以外の言語にも、同じような仕組みがあります。

どの言語でも「他の人が作った便利なコードを再利用する」という考え方は共通です。
</Callout>

### 2. 情報が豊富で学びやすい

Node.jsはWeb開発の主流技術であり、学習リソースが非常に充実しています。

**TypeScriptとの相性が抜群**

現在の開発現場では、JavaScriptではなく**TypeScript**を使うのが主流です。

TypeScriptはJavaScriptに「型」を追加した言語で、より安全で保守しやすいコードが書けます。<br/>
そしてTypeScriptを動かすにはNode.jsが必要です。

<small>※厳密には、『TypeScriptをコンパイルするにはnode.jsが必要』という表現が正しいです。</small>

```bash
# TypeScriptのインストール（Node.jsが必要）
npm install typescript
```

**フレームワークやライブラリが豊富**

Node.jsのエコシステムには、さまざまな用途のフレームワークやライブラリが揃っています。

これらはすべてNode.js上で動作し、日本語の解説記事やチュートリアルも多く公開されています。

**フロントエンドもバックエンドも同じ言語**

Node.jsがあれば、Webサイトの表示部分（フロントエンド）も、サーバー側の処理（バックエンド）も、どちらもJavaScript/TypeScriptで書けます。

1つの言語で両方できるため、学習効率が良いです。
