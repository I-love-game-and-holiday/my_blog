## Node.js とは

**Node.js**(ノードジェーエス) は、JavaScriptの実行環境の一つです。

JavaScriptは元々ブラウザ（ChromeやEdgeなど）の中でしか動かせない言語でした。<br />
Node.jsがあれば、ブラウザがなくてもJavaScriptを実行できます。

## なぜ Node.js が必要なのか

### 1. モダンな開発では必須

現代のWeb開発では、JavaScriptを使った様々なツールが使われています。<br />
これらのツールはNode.js上で動くため、インストールが必須です。

例えば、このサイトは**Next.js**というフレームワークで作られています。<br />
Next.jsを動かすにはNode.jsが必要です。

```bash
# Node.jsがないと、このコマンドは動かない
npm install
npm run dev
```

### 2. パッケージ管理ができる

Node.jsをインストールすると、**npm（Node Package Manager）** というツールが一緒についてきます。

npmを使うと、世界中の開発者が作った便利なライブラリ（パッケージ）を簡単にインストールできます。

```bash
# 例: 日付を扱いやすくするライブラリをインストール
npm install dayjs
```

<Callout type="info">
**パッケージとは**

誰かが作った便利なプログラムの塊です。<br />
ゼロから全部作らなくても、パッケージを組み合わせることで効率的に開発できます。
</Callout>

### 3. 学習コースで必要

このサイトの学習コース（ToDoアプリなど）では、Node.jsを使って開発を進めます。<br />
まずはNode.jsをインストールしておきましょう。
