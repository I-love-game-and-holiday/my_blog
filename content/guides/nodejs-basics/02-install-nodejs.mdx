## 公式サイトからインストール

### 1. ダウンロード

下記リンクから、お使いのOSに合ったインストーラーをダウンロードしてください。

<a href="https://nodejs.org/ja" target="_blank" rel="noopener noreferrer">Node.js公式サイト</a>

  caption="『Node.js🄬を入手』をクリック"

ダウンロードページを開くと、自動で最新の安定バージョンである**LTS**が設定されます。<br />

### 2. インストール

ダウンロードしたファイルを実行し、画面の指示に従ってインストールしてください。<br />
基本的に「次へ」を押していけばOKです。

## インストールを確認する

ターミナル（PowerShellやターミナル.app）を開いて、以下のコマンドを実行してください。

```bash
node -v
```

バージョン番号が表示されれば成功です。

```bash
# 実行結果の例
v22.13.0
```

npmも一緒にインストールされているか確認しましょう。

```bash
npm -v
```

```bash
# 実行結果の例
10.9.2
```

<Callout type="warning">
**コマンドが見つからない場合**

「'node' は、内部コマンドまたは...」のようなエラーが出る場合は、ターミナルやエディターを一度閉じて開き直してください。<br />
</Callout>

## バージョン管理ツールについて

開発を続けていると、プロジェクトやアプリによって異なるNode.jsバージョンを使い分けたくなることがあります。<br />
その場合は**バージョン管理ツール**を使います。

とりあえず、バージョンを分けられるということだけ頭に入れておいて必要になったら調べるようにしてください。
