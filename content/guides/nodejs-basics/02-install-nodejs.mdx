## 公式サイトからインストール

### 1. ダウンロード

下記リンクから、お使いのOSに合ったインストーラーをダウンロードしてください。

<a href="https://nodejs.org/ja" target="_blank" rel="noopener noreferrer">Node.js公式サイト</a>

トップページに2つのバージョンが表示されています。<br />
**LTS（長期サポート版）** を選んでください。安定していて、初心者にはこちらがお勧めです。

{/* TODO: 公式サイトのスクリーンショットを追加 */}

<Callout type="info">
**LTSとは**

Long Term Support（長期サポート）の略です。<br />
安定性を重視したバージョンで、企業の本番環境でもよく使われています。
</Callout>

### 2. インストール

ダウンロードしたファイルを実行し、画面の指示に従ってインストールしてください。<br />
基本的に「次へ」を押していけばOKです。

<Callout type="info">
**Macをお使いの方へ**

初回起動時に「開発元が未確認」という警告が出る場合があります。<br />
その場合は「システム設定」→「プライバシーとセキュリティ」から許可してください。
</Callout>

## インストールを確認する

ターミナル（PowerShellやターミナル.app）を開いて、以下のコマンドを実行してください。

```bash
node -v
```

バージョン番号が表示されれば成功です。

```bash
# 実行結果の例
v22.13.0
```

npmも一緒にインストールされているか確認しましょう。

```bash
npm -v
```

```bash
# 実行結果の例
10.9.2
```

<Callout type="warning">
**コマンドが見つからない場合**

「'node' は、内部コマンドまたは...」のようなエラーが出る場合は、ターミナルを一度閉じて開き直してください。<br />
それでも動かない場合は、PCを再起動してみてください。
</Callout>

## バージョン管理ツールについて

開発を続けていると、プロジェクトによって異なるNode.jsバージョンを使い分けたくなることがあります。<br />
その場合は**バージョン管理ツール**を使います。
