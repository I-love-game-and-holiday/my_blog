## 起きていた問題

サイトのコードブロックに設置した「コピー」ボタンでcurlコマンドをコピーし、VSCodeのターミナルに貼り付けると、**コマンドの出力結果がHTMLソースになる**という現象が発生しました。

```
PS> curl -X POST http://localhost:3000/records/clock-out ^
  -H "Content-Type: application/json" ^
  -d "{\"id\": \"4\", \"clockOut\": \"18:00\"}"
```

を実行すると、APIのJSONレスポンスではなく `<!DOCTYPE html><html lang="ja">...` という404ページのHTMLが返ってきます。

一方、**メモ帳に貼り付けるとコマンドは正常に表示される**ため、最初はクリップボードやコピー機能の不具合を疑い、かなり遠回りしてしまいました。

## 調査の過程（遠回り編）

クリップボードに `text/html` フォーマットが混入しているのでは？と考え、以下を順番に試しました。

```typescript
// 試行1: writeText → write + ClipboardItem に変更
const blob = new Blob([text], { type: 'text/plain' })
await navigator.clipboard.write([
    new ClipboardItem({ 'text/plain': blob }),
])

// 試行2: textarea + execCommand に変更
const textarea = document.createElement('textarea')
textarea.value = text
document.body.appendChild(textarea)
textarea.select()
document.execCommand('copy')

// 試行3: copy イベントをフックして text/plain のみ書き込み
const handler = (ev: ClipboardEvent) => {
    ev.preventDefault()
    ev.clipboardData?.setData('text/plain', text)
}
document.addEventListener('copy', handler)
document.execCommand('copy')
document.removeEventListener('copy', handler)
```

どれを試しても症状は変わりませんでした。

ここで `navigator.clipboard.read()` でクリップボードの中身を読み取ってみると、**`text/plain` のみで、中身も正しいcurlコマンド**。クリップボードに問題はありませんでした。

## 真の原因

**curlコマンドの行継続文字が、PowerShellの構文と合っていなかった**のが原因でした。

サイトの Windows タブには `cmd.exe` 用の構文でコマンドを書いていました。

```
curl -X POST http://localhost:3000/records/clock-out ^
  -H "Content-Type: application/json" ^
  -d "{\"id\": \"4\", \"clockOut\": \"18:00\"}"
```

`^` は **cmd.exe の行継続文字**です。しかし、VSCode のターミナルはデフォルトで **PowerShell** を使います。

PowerShell では `^` は行継続文字として認識されないため、1行目の `curl ... ^` だけが実行されます。その結果、`http://localhost:3000/records/clock-out` にヘッダーもボディもない不正なリクエストが送られ、Next.js の 404 ページ（HTML）がレスポンスとして返ってきていたのです。

「メモ帳に貼り付けると正常」だったのは、メモ帳はコマンドを実行しないのでテキストがそのまま表示されるだけだからです。

## 解決策

Windows 用のコマンドを **PowerShell の構文**に修正しました。

| 項目 | cmd.exe | PowerShell |
|------|---------|------------|
| 行継続文字 | `^` | `` ` ``（バッククォート） |
| curl コマンド | `curl` | `curl.exe`（エイリアス回避） |

```powershell
# 修正後（PowerShell）
curl.exe -X POST http://localhost:3000/records/clock-out `
  -H "Content-Type: application/json" `
  -d '{"id": "4", "clockOut": "18:00"}'
```

### ポイント

- **`curl.exe`**: PowerShell の `curl` は `Invoke-WebRequest` のエイリアスなので、`curl.exe` と明示的に書く
- **バッククォート**: PowerShell の行継続文字は `^` ではなく `` ` ``
- **シングルクォート**: PowerShell のシングルクォート内は変数展開されないので、JSON をそのまま書ける

## まとめ

「コピーした内容がHTMLになる」と思い込んでクリップボード API を深掘りしましたが、実際には **コマンドは正しくコピーされていて、実行結果がHTMLだった** というオチでした。

思い込みで原因を決めつけず、**何が本当に起きているのか**を一つずつ切り分けることの大切さを再認識しました。
