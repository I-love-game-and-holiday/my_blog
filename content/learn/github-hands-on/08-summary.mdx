## 身についたスキル

このコースを通して、以下のスキルが身につきました。

### Git の基本操作

- **コミットの習慣** — 変更を記録し、いつでも過去の状態に戻れる開発ができる
- **差分の確認** — `git diff` や `git status` で、何が変わったかを常に把握できる
- **安全な取り消し** — 間違えても `git restore` で変更前に戻せる

### GitHub での共同開発

- **リモート連携** — ローカルの変更を GitHub に公開し、チームで共有できる
- **ブランチ戦略** — 機能ごとにブランチを切り、メインのコードを安全に保てる
- **プルリクエスト** — コードレビューを通じてマージする開発フローを実践できる
- **コンフリクト解消** — 衝突が起きても冷静に対処し、手動で解消できる

### GUI ツールという選択肢

このコースでは Git のすべての操作をターミナル（コマンドライン）で行いましたが、**GUI ツール**を使う方法もあります。

- **<a href="https://desktop.github.com/" target="_blank" rel="noopener noreferrer">GitHub Desktop</a>** — GitHub 公式のデスクトップアプリ。視覚的に操作できるので初心者にも使いやすい
- **VS Code の Git 機能** — エディタに内蔵された Git 操作。コミットやブランチ切り替えがボタンひとつでできる

GUI ツールの裏側で動いているのは、このコースで学んだのと同じ Git コマンドです。コマンドを理解した上で GUI を使えば、何か問題が起きたときにも対処できます。
