## Step 1: 要素を取得する

まず、HTMLの要素をJavaScriptから操作できるようにします。

```js title="main.js"
// HTML要素を取得
const form = document.getElementById('todo-form');
const input = document.getElementById('todo-input');
const list = document.getElementById('todo-list');

// タスクを保存する配列
let todos = [];
```

<Callout type="info">
`document.getElementById()` は、HTMLの `id` 属性を使って要素を取得するメソッドです。
</Callout>

## Step 2: タスクを表示する関数を作る

配列 `todos` の中身を画面に表示する関数を作ります。

```js title="main.js"
// タスクを画面に表示する関数
function renderTodos() {
  // 一旦リストを空にする
  list.innerHTML = '';

  // todos配列の中身を1つずつ処理
  todos.forEach((todo, index) => {
    const li = document.createElement('li');
    li.className = 'todo-item';
    li.innerHTML = `
      <input type="checkbox">
      <span>${todo.text}</span>
      <button type="button">削除</button>
    `;
    list.appendChild(li);
  });
}
```

### ポイント

- `innerHTML = ''` でリストを空にしてから再描画します
- `forEach` で配列の要素を1つずつ処理します
- `createElement` で新しいHTML要素を作成します

## 完成コード

ここまでの `main.js` の全体像です。

<CollapsibleCode title="main.js 全体" defaultOpen={false}>
```js
// HTML要素を取得
const form = document.getElementById('todo-form');
const input = document.getElementById('todo-input');
const list = document.getElementById('todo-list');

// タスクを保存する配列
let todos = [];

// タスクを画面に表示する関数
function renderTodos() {
  list.innerHTML = '';

  todos.forEach((todo, index) => {
    const li = document.createElement('li');
    li.className = 'todo-item';
    li.innerHTML = `
      <input type="checkbox">
      <span>${todo.text}</span>
      <button type="button">削除</button>
    `;
    list.appendChild(li);
  });
}

// フォーム送信時の処理
form.addEventListener('submit', (e) => {
  e.preventDefault();

  const text = input.value;

  if (!text.trim()) {
    return;
  }

  todos.push({ text: text });
  renderTodos();
  input.value = '';
});
```
</CollapsibleCode>
