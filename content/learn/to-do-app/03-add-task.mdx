## Step 1: 要素を取得する

まず、HTMLの要素をJavaScriptから操作できるようにします。

```js title="main.js"
// HTML要素を取得
const form = document.getElementById('todo-form');
const input = document.getElementById('todo-input');
const list = document.getElementById('todo-list');

// タスクを保存する配列
let todos = [];
```

<Callout type="info">
`.getElementById()` は、HTMLの `id` 属性を使って要素を取得するメソッドです。
<a href="https://developer.mozilla.org/ja/docs/Web/API/Document/getElementById" target="_blank" rel="noopener noreferrer">(参考)</a>
</Callout>

## Step 2: タスクを表示する関数を作る

配列 `todos` の中身を画面に表示する関数を作ります。

```js title="main.js"
// タスクを画面に表示する関数
function renderTodos() {
  // 一旦リストを空にする
  list.innerHTML = '';

  // todos配列の中身を1つずつ処理
  todos.forEach((todo) => {
    const li = document.createElement('li');
    li.className = 'todo-item';
    li.innerHTML = `
      <input type="checkbox">
      <span>${todo.text}</span>
      <button type="button">削除</button>
    `;
    list.appendChild(li);
  });
}
```

### ポイント

- `innerHTML = ''` でリストを空にしてから再描画します（なぜ再描画の必要があるか考えてみましょう）
- `forEach` で配列の要素を1つずつ処理します
- `createElement` で新しいHTML要素を作成します

## Step 3: タスクを追加する処理を作る

ここからが本番です。フォームが送信されたときの処理を書きます。

### イベントリスナーについて

`addEventListener()`を使うと、「このボタンがクリックされたら〇〇する」のような処理を設定できます。


<LearnMore>
`addEventListener()`はDOM要素が持つメソッドです。

第1引数にイベント名（`'click'`、`'submit'`など）、第2引数に実行したい関数を渡します。

今回はHTMLのフォームでsubmitイベントが発火すると、第2引数の関数が実行されます。
</LearnMore>

```js title="main.js"
// フォーム送信時の処理
form.addEventListener('submit', (e) => {

  e.preventDefault();

  // ========================================
  // ここを自分で考えて実装してみよう！
  // ========================================
  // やること:
  // 1. 入力欄の値を取得する（input.value）
  // 2. 空欄チェック（空なら何もしないで return）
  // 3. todosに新しいタスクを追加する
  //    → { text: 入力値 } というオブジェクトで追加
  // 4. renderTodos() を呼んで画面を更新
  // 5. 入力欄を空にする（input.value = ''）
  // ========================================


});
```
<Callout type="info">
**preventDefault** はブラウザのデフォルト動作をキャンセルするメソッドです。
</Callout>

<Callout type="warning">
**まずは自分で考えてみましょう！**

5〜10分ほど試してみて、分からなければ下のヒントを見てください。
</Callout>

### ヒント

<CollapsibleCode title="ヒント1: 入力値の取得と空白除去" defaultOpen={false}>
```js
const text = input.value.trim();
```
`trim()` は前後の空白を除去します。
</CollapsibleCode>

<CollapsibleCode title="ヒント2: 空欄チェック" defaultOpen={false}>
```js
if (!text) {
  return;
}
```
空白除去後に空文字なら何もしません。
</CollapsibleCode>

<CollapsibleCode title="ヒント3: 配列への追加" defaultOpen={false}>
```js
todos.push({ text });
```
`{ text }` は `{ text: text }` の省略記法です。プロパティ名と変数名が同じ場合に使えます。
</CollapsibleCode>

### 答え

<CollapsibleCode title="答えを見る" defaultOpen={false}>
```js
form.addEventListener('submit', (e) => {
  e.preventDefault();

  // 1. 入力欄の値を取得（前後の空白を除去）
  const text = input.value.trim();

  // 2. 空欄チェック
  if (!text) {
    return;
  }

  // 3. todosに新しいタスクを追加
  todos.push({ text });

  // 4. 画面を更新
  renderTodos();

  // 5. 入力欄を空にする
  input.value = '';
});
```

## 完成コード

ここまでの `main.js` の全体像です。

<CollapsibleCode title="main.js 全体" defaultOpen={false}>
```js
// HTML要素を取得
const form = document.getElementById('todo-form');
const input = document.getElementById('todo-input');
const list = document.getElementById('todo-list');

// タスクを保存する配列
let todos = [];

// タスクを画面に表示する関数
function renderTodos() {
  list.innerHTML = '';

  todos.forEach((todo) => {
    const li = document.createElement('li');
    li.className = 'todo-item';
    li.innerHTML = `
      <input type="checkbox">
      <span>${todo.text}</span>
      <button type="button">削除</button>
    `;
    list.appendChild(li);
  });
}

// フォーム送信時の処理
form.addEventListener('submit', (e) => {
  e.preventDefault();

  const text = input.value.trim();

  if (!text) {
    return;
  }

  todos.push({ text });
  renderTodos();
  input.value = '';
});
```
</CollapsibleCode>

<Callout type="info">
**セキュリティについて**

今回は `innerHTML` を使っていますが、このTodoアプリはデータベースがなく、自分の入力を自分で見るだけなので問題ありません。

ただし、他のユーザーの入力を表示するアプリ（掲示板、SNSなど）では、悪意あるスクリプトが実行される危険があります（XSS攻撃）。今後の開発では気をつけましょう。
</Callout>
