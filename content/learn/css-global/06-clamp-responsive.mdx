## レスポンシブ対応

> PCでは大きく表示したいけれど、スマホでは画面幅に収まるよう小さくしたい。

こういった目的のために「画面幅に応じてサイズを変える」ことを**レスポンシブ対応**と呼びます。

## レスポンシブの2つのアプローチ

CSSでレスポンシブ対応を実現する主要な方法は**2つ**あります。

    ["clamp()", "画面幅に応じて滑らかに変化する", "フォントサイズ、余白、幅などのサイズ値"],
  ]}
/>

どちらが優れているかではなく、**得意な場面が違います**。このレッスンでは両方の特徴を理解した上で、`clamp()` の書き方を学びます。

<LearnMore>
この2つ以外に、**コンテナクエリ**（`@container`）という方法もあります。メディアクエリが「画面全体の幅」で切り替えるのに対し、コンテナクエリは「親要素の幅」で切り替えます。同じコンポーネントをサイドバーにもメインカラムにも配置できる場面で便利です。2023年に主要ブラウザすべてで対応し、実務でも採用が進んでいます。
</LearnMore>

## メディアクエリはブレークポイントで「切り替える」

**メディアクエリ**（`@media`）は、画面幅がある値を超えたらスタイルを切り替える方法です。

```css title="style.css"
h1 {
  font-size: 18px;
}

@media (min-width: 768px) {
  h1 {
    font-size: 32px;
  }
}
```

これは「画面幅が768px以上になったら、`h1` のフォントサイズを32pxに変える」という意味です。

この方法でも目的は達成できますが、1つ問題があります。

<ContentTable

    ["768px", "32px", "← ここで一気に14px大きくなる"],
    ["1920px", "32px", ""],

768pxを境に、フォントサイズが**一気に切り替わります**。スライダーを動かして、768px付近で「カクッ」と変わる瞬間を確認してみましょう。

メディアクエリはレイアウトの**構造を切り替える**場面で力を発揮します。「スマホでは縦並び、PCでは横並び」「スマホではメニューを隠す」といった、**表示するかしないかの二択**に向いています。

一方で、フォントサイズや余白のように**少しずつ変えたい**値には、次に紹介する `clamp()` が適しています。

## clamp() は画面幅に応じて「滑らかに」変化させる

`clamp()` を使うと、画面幅に応じてフォントサイズが**滑らかに**変化します。

```css title="style.css"
h1 {
  font-size: clamp(1.125rem, 0.6rem + 2.2vw, 2rem);
}
```

メディアクエリのような「境界線」はありません。画面幅に連動して、最小値と最大値の間を滑らかに移動します。

<ResponsivePreview
  title="clamp(): 画面幅に応じて滑らかに変化する"
  height={210}
  minWidth={320}
  maxWidth={1280}
  defaultWidth={600}
  html={`<div class="card"><h1>見出しテキスト</h1><p>スライダーをゆっくり動かしてみてください。滑らかに変化します。</p></div>`}
  css={`
    body { font-family: system-ui, sans-serif; margin: 16px; }
    .card {
      padding: clamp(1rem, 0.5rem + 2vw, 2rem);

      border: 1px solid #bfdbfe;
      border-radius: 8px;
    }
    h1 { font-size: clamp(1.125rem, 0.6rem + 2.2vw, 2rem); margin-bottom: 8px; }
    p { color: #737373; font-size: clamp(0.875rem, 0.8rem + 0.3vw, 1rem); line-height: 1.5; }
  `}
/>

### clamp() の3つの引数

`clamp()` には3つの値を渡します。

```css title="構文"
clamp(最小値, 推奨値, 最大値)
```

<ContentTable
  headers={["引数", "役割", "例"]}
  rows={[
    ["最小値", "これより小さくならない", "1.125rem（18px）"],
    ["推奨値", "画面幅に応じて計算される値", "0.6rem + 2.2vw"],
    ["最大値", "これより大きくならない", "2rem（32px）"],
  ]}
/>

実際のコードを分解してみましょう。

```css title="style.css"
h1 {
  font-size: clamp(1.125rem, 0.6rem + 2.2vw, 2rem);
}
```

- **`1.125rem`**（18px）: スマホでもこれ以上は小さくならない
- **`0.6rem + 2.2vw`**: ビューポート幅に応じて計算される値。`1vw` は画面幅の1%
- **`2rem`**（32px）: PCでもこれ以上は大きくならない

推奨値の `2.2vw` がポイントです。画面幅が広がると `vw` の値も大きくなるため、フォントサイズが連動して変化します。

<LearnMore>
`rem` はルート要素（`html`）のフォントサイズを基準とした単位です。ブラウザのデフォルトでは `1rem = 16px` です。

<ContentTable
  headers={["値", "計算", "結果"]}
  rows={[
    ["1.125rem", "16px × 1.125", "18px"],
    ["2rem", "16px × 2", "32px"],
  ]}
/>

`px` ではなく `rem` を使う理由は、ユーザーがブラウザの文字サイズ設定を変更したときに、サイト全体のフォントサイズが連動して変わるようにするためです。アクセシビリティの観点から、フォントサイズには `rem` を使うのが推奨されています。
</LearnMore>

## フォントサイズ以外にも使える

`clamp()` はフォントサイズ専用の機能ではありません。**サイズを表すあらゆるプロパティ**に使えます。

```css title="style.css"
/* 余白を滑らかに変化させる */
.section {
  padding: clamp(0.75rem, 0.1rem + 3vw, 3.5rem);
}

/* コンテンツ幅を滑らかに変化させる */
.container {
  max-width: clamp(20rem, 90%, 56rem);
}
```

<ResponsivePreview
  title="clamp() でパディングを滑らかに変化させる"
  height={260}
  minWidth={320}
  maxWidth={1280}
  defaultWidth={500}
  html={`
    <div class="section">
      <h1>見出しテキスト</h1>

    </div>
  `}
  css={`
    body { font-family: system-ui, sans-serif; margin: 0; }
    .section {
      padding: clamp(0.75rem, 0.1rem + 3vw, 3.5rem);
      background-color: #f0f9ff;
      border: 1px solid #bfdbfe;
    }
    h1 {
      font-size: clamp(1.125rem, 0.6rem + 2.2vw, 2rem);
      margin-bottom: 8px;
    }
    p {
      line-height: 1.6;
      font-size: clamp(0.875rem, 0.8rem + 0.3vw, 1rem);
    }
  `}
/>

<Callout type="info">
冒頭で見た2つのアプローチを思い出しましょう。構造の切り替え（表示/非表示、縦/横）は**メディアクエリ**、サイズ値の滑らかな変化は **`clamp()`**。それぞれの得意分野を使い分けるのがポイントです。
</Callout>

<LearnMore>
推奨値の計算式（`1.25rem + 1vw` のような部分）を自分で考えるのは大変です。最小値と最大値を入力すると、推奨値を自動計算してくれるツールがあります。

- [Utopia](https://utopia.fyi/type/calculator/) — フォントサイズや余白のclamp()を自動生成
- [clamp() Calculator](https://www.marcbacon.com/tools/clamp-calculator/) — シンプルなclamp()計算機

最小値・最大値・対応する画面幅を入力するだけで、推奨値を含む `clamp()` 式が生成されます。
</LearnMore>
