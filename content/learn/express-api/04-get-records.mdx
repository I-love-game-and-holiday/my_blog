## このレッスンで作るもの

勤怠管理APIの最初のエンドポイントを作ります。

- `GET /records` - 勤務記録の一覧を取得
- `GET /records/:id` - 特定の勤務記録を取得

## Step 1: データの型を定義する

まず、勤務記録のデータ構造を TypeScript の型で定義します。

`src/types.ts` を作成してください。

```typescript title="src/types.ts"
export interface AttendanceRecord {
  id: string;
  employeeName: string;
  date: string;          // "2026-01-28"
  clockIn: string;       // "09:00"
  clockOut: string | null;
  note?: string;         // 備考（遅刻理由など）
}
```

<Callout type="info">
`clockOut` が `string | null` なのは、出勤はしたけどまだ退勤していない状態を表すためです。

`note?` の `?` は「省略可能（optional）」を意味します。TypeScript入門ガイドで学んだ内容ですね。
</Callout>

## Step 2: モックデータを作成する

実際のデータベースの代わりに、配列でデータを管理します。

`src/data.ts` を作成してください。

```typescript title="src/data.ts"
import { AttendanceRecord } from './types.js';

let records: AttendanceRecord[] = [
  {
    id: '1',
    employeeName: '田中太郎',
    date: '2026-01-27',
    clockIn: '09:00',
    clockOut: '18:00',
    note: '',
  },
  {
    id: '2',
    employeeName: '佐藤花子',
    date: '2026-01-27',
    clockIn: '08:45',
    clockOut: '17:30',
  },
  {
    id: '3',
    employeeName: '田中太郎',
    date: '2026-01-28',
    clockIn: '09:15',
    clockOut: null,
    note: '電車遅延',
  },
];

let nextId = 4;

export function getRecords(): AttendanceRecord[] {
  return records;
}

export function getRecordById(id: string): AttendanceRecord | undefined {
  return records.find((record) => record.id === id);
}

export function addRecord(record: AttendanceRecord): void {
  records.push(record);
}

export function updateRecord(id: string, updates: Partial<AttendanceRecord>): AttendanceRecord | undefined {
  const index = records.findIndex((record) => record.id === id);
  if (index === -1) return undefined;

  records[index] = { ...records[index], ...updates };
  return records[index];
}

export function deleteRecord(id: string): boolean {
  const index = records.findIndex((record) => record.id === id);
  if (index === -1) return false;

  records.splice(index, 1);
  return true;
}

export function generateId(): string {
  const id = String(nextId);
  nextId++;
  return id;
}
```

<Callout type="info">
import 文のパスに `.js` が付いていることに気づきましたか？

TypeScriptは `.ts` ファイルをコンパイルすると `.js` になります。Node.jsの ESModules では、実行時に存在するファイルのパス（`.js`）を指定する必要があります。少し不思議ですが、TypeScriptの仕様です。
</Callout>

<LearnMore>
`Partial<AttendanceRecord>` は TypeScript の **ユーティリティ型** です。

`AttendanceRecord` の全てのプロパティを省略可能にした型を作ります。更新時には一部のプロパティだけ変更したいケースがあるため、`Partial` を使っています。

```typescript
// Partial<AttendanceRecord> は以下と同じ意味
{
  id?: string;
  employeeName?: string;
  date?: string;
  clockIn?: string;
  clockOut?: string | null;
  note?: string;
}
```
</LearnMore>

## Step 3: 一覧取得APIを作る

`src/index.ts` を修正して、`GET /records` エンドポイントを追加します。

```typescript title="src/index.ts"
import express from 'express';
import { getRecords, getRecordById } from './data.js';

const app = express();

app.use(express.json());

const PORT = 3000;

// 勤務記録の一覧を取得
app.get('/records', (req, res) => {
  const records = getRecords();
  res.json(records);
});

app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`);
});
```

## Step 5: 個別取得APIを作る

特定のIDの記録を取得する `GET /records/:id` を追加します。

```typescript title="src/index.ts" {4,9-18}
// 勤務記録の一覧を取得
app.get('/records', (req, res) => {
  const records = getRecords();
  res.json(records);
});

// 特定の勤務記録を取得
app.get('/records/:id', (req, res) => {
  const record = getRecordById(req.params.id);

  if (!record) {
    res.status(404).json({ error: '記録が見つかりません' });
    return;
  }

  res.json(record);
});
```

### ルートパラメータ

`:id` の部分は **ルートパラメータ** と呼ばれ、URLの一部を変数として受け取れます。

```
GET /records/1  →  req.params.id は "1"
GET /records/2  →  req.params.id は "2"
```

### ステータスコード

`res.status(404)` はHTTPステータスコードを設定しています。
