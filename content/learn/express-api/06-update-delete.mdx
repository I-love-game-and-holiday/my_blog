## このレッスンで作るもの

CRUDの残り2つ、**U**pdate と **D**elete を実装します。

- `PUT /records/:id` - 打刻の修正
- `DELETE /records/:id` - 記録の削除

## なぜ修正・削除が必要なのか

勤怠管理では、こんな場面が日常的にあります。

- 出勤時刻を間違えて打刻した → **修正**
- 間違って登録してしまった記録がある → **削除**

実務のシステムでは当たり前に存在する機能です。

## Step 1: 修正APIを作る

`src/index.ts` に `PUT /records/:id` を追加します。退勤打刻のエンドポイントの下に追加してください。

```typescript title="src/index.ts"
import express from 'express';
import {
  getRecords,
  getRecordById,
  addRecord,
  updateRecord,
  deleteRecord,
  generateId,
} from './data.js';

// ... 既存のエンドポイント ...

// 記録を修正
app.put('/records/:id', (req, res) => {
  const { id } = req.params;
  const updates = req.body;

  const updatedRecord = updateRecord(id, updates);

  if (!updatedRecord) {
    res.status(404).json({ error: '記録が見つかりません' });
    return;
  }

  res.json(updatedRecord);
});
```

### PUTメソッドについて

`PUT` は既存のリソースを更新するためのHTTPメソッドです。

```
PUT /records/3  →  ID:3 の記録を更新
```

`req.params.id` でURLのIDを取得し、`req.body` で更新したいデータを受け取ります。

## Step 3: 削除APIを作る

`DELETE /records/:id` を追加します。

```typescript title="src/index.ts"
// 記録を削除
app.delete('/records/:id', (req, res) => {
  const { id } = req.params;

  const deleted = deleteRecord(id);

  if (!deleted) {
    res.status(404).json({ error: '記録が見つかりません' });
    return;
  }

  res.status(204).send();
});
```

### ステータスコード 204

`204 No Content` は「処理は成功したが、返すデータはない」を意味します。削除が成功した場合、返すべきデータがないため `204` を使います。

`res.status(204).send()` は、ボディなしのレスポンスを返します。

## 完成コード

<CollapsibleCode title="src/index.ts 全体" defaultOpen={false}>
```typescript
import express from 'express';
import {
  getRecords,
  getRecordById,
  addRecord,
  updateRecord,
  deleteRecord,
  generateId,
} from './data.js';

const app = express();

app.use(express.json());

const PORT = 3000;

// 勤務記録の一覧を取得
app.get('/records', (req, res) => {
  const records = getRecords();
  res.json(records);
});

// 特定の勤務記録を取得
app.get('/records/:id', (req, res) => {
  const record = getRecordById(req.params.id);

  if (!record) {
    res.status(404).json({ error: '記録が見つかりません' });
    return;
  }

  res.json(record);
});

// 出勤打刻
app.post('/records/clock-in', (req, res) => {
  const { employeeName, date, clockIn, note } = req.body;

  if (!employeeName || !date || !clockIn) {
    res.status(400).json({ error: 'employeeName, date, clockIn は必須です' });
    return;
  }

  const newRecord = {
    id: generateId(),
    employeeName,
    date,
    clockIn,
    clockOut: null,
    note: note || '',
  };

  addRecord(newRecord);
  res.status(201).json(newRecord);
});

// 退勤打刻
app.post('/records/clock-out', (req, res) => {
  const { id, clockOut } = req.body;

  if (!id || !clockOut) {
    res.status(400).json({ error: 'id, clockOut は必須です' });
    return;
  }

  const record = getRecordById(id);

  if (!record) {
    res.status(404).json({ error: '記録が見つかりません' });
    return;
  }

  if (record.clockOut !== null) {
    res.status(400).json({ error: 'すでに退勤が記録されています' });
    return;
  }

  record.clockOut = clockOut;
  res.json(record);
});

// 記録を修正
app.put('/records/:id', (req, res) => {
  const { id } = req.params;
  const updates = req.body;

  const updatedRecord = updateRecord(id, updates);

  if (!updatedRecord) {
    res.status(404).json({ error: '記録が見つかりません' });
    return;
  }

  res.json(updatedRecord);
});

// 記録を削除
app.delete('/records/:id', (req, res) => {
  const { id } = req.params;

  const deleted = deleteRecord(id);

  if (!deleted) {
    res.status(404).json({ error: '記録が見つかりません' });
    return;
  }

  res.status(204).send();
});

app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`);
});
```
