## リポジトリとは

リポジトリ（repo）は、プロジェクトの全ての変更履歴を保存する場所です。

## リポジトリを作成する

1. 作業フォルダを作成:

```bash
mkdir my-first-repo
cd my-first-repo
```

2. Gitリポジトリを初期化:

```bash
git init
```

これで `.git` という隠しフォルダが作成され、このフォルダがGitリポジトリになります。

## 最初のファイルを作る

```bash
echo "# My First Repository" > README.md
```

## 状態を確認する

```bash
git status
```

出力:

```
Untracked files:
  README.md
```

`Untracked` = Gitがまだ追跡していないファイル

## ファイルをステージングする

```bash
git add README.md
```

もう一度 `git status`:

```
Changes to be committed:
  new file: README.md
```

## コミットする

```bash
git commit -m "最初のコミット"
```

おめでとうございます！最初のコミットが完了しました。
