## インストール方法

お使いのOSに合わせてGitをインストールします。

### Windows

1. [git-scm.com](https://git-scm.com/) にアクセス
2. 「Download for Windows」をクリック
3. ダウンロードしたファイルを実行
4. 基本的にデフォルト設定のまま「Next」で進む

### Mac

ターミナルを開いて以下を実行:

```bash
git --version
```

インストールされていなければ、Xcodeコマンドラインツールのインストールを促されます。

## インストール確認

ターミナル（またはコマンドプロンプト）で以下を実行:

```bash
git --version
```

バージョンが表示されれば成功です。

```
git version 2.43.0
```

## 初期設定

名前とメールアドレスを設定します:

```bash
git config --global user.name "あなたの名前"
git config --global user.email "your-email@example.com"
```

次のレッスンでは、最初のリポジトリを作成します。
