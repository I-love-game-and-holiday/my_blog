github の main ブランチへ成果物をプッシュすると、vercel は自動で検知してホスティング(だれでもアクセスできる状態)してくれます。

このデプロイ成功をトリガーに、自動ツイートのアクションを発火させたいですね

## deployment_status をトリガーにする

github にはサードパーティが連携できるように公開された公式 API があります。そのひとつに『**deployment_status**』があります。

> GitHub ドキュメントより
>
> https://docs.github.com/ja/actions/reference/workflows-and-actions/events-that-trigger-workflows#deployment_status

『**deployment_status**』はデプロイの成否を受け取ります。ドキュメントには、この status をトリガーとして処理を実行できると記載されています。

つまり、vercel がデプロイの成否をわざわざ github の API を叩いて、
開発者が利用しやすいように配慮してくれていたってことですよね。普段まったく意識せずに利用できていたのは陰ながらの配慮や工夫のお陰なんですね。
ありがたい限りです。

## deployment_status 受け取りテスト

ルートに **github\workflows** ディレクトリを作成し、下記.yml ファイルを作成します。
**on**は起動トリガーで deployment_status イベントが起きたら jobs が実行されます。

deployment_status を echo で出力して確認してみます。

```yml filename="tweet-on-vercel-deploy.yml"
name: Tweet on Vercel Production Deploy

on:
  deployment_status:

jobs:
  tweet:
    runs-on: ubuntu-latest
    steps:
      - name: Debug - Check deployment_status event
        run: |
          echo "=== Deployment Status Event ==="
          echo "State: ${{ github.event.deployment_status.state }}"
          echo "Environment: ${{ github.event.deployment_status.environment }}"
```
