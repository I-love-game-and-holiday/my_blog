# sql って画像保存できるんですか!?

非構造化データ(画像や動画など)は AWS S3 のようなオブジェクトストレージが担うイメージが強かったのですが、 SQL でも保存できると聞いたので試してみます。

<Alert variant="note">
  この記事はハンズオン形式で blob に画像保存ができることを確認します。
</Alert>

## BLOB(ブロブ)型とは

- **バイナリデータを格納するためのデータ型**
- 文字コードに依存しない生のデータをそのまま保存でき、サイズによって TINYBLOB、BLOB、MEDIUMBLOB、LONGBLOB の 4 種類がある

## ハンズオン

docker で mysql 環境を作ります。

```yml filename="docker-compose.yml"
version: "3.8"

services:
mysql-server:
image: mysql:8.0
container_name: mysql-server
environment:
MYSQL_ROOT_PASSWORD: rootpassword
MYSQL_DATABASE: testdb
TZ: Asia/Tokyo
ports: - "3306:3306"
volumes: - mysql-data:/var/lib/mysql - ./app:/app
working_dir: /app
command: --default-authentication-plugin=mysql_native_password

volumes:
mysql-data:
```
