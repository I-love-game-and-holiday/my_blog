# 今更 ですが、pytest を勉強する

私は日系 SIer に新卒で就職しました。官公庁独特？日本企業独特？なのか知りませんが、当時は一挙手一投足スクリーンショットを撮りながらテスト環境の実機を動かしていました。

ほとんどの言語にはテスト機能を自動化するツールやフレームワークがあります。例えば Python には pytest というフレームワークがあり、簡単にテストができるようです

<Alert variant="note">Pythonフレームワーク『pytest』の基本操作を学びます</Alert>

> Python 3.12.0 で検証しました(pytest をインストールしてください)

## pytest 特徴

- テストファイルの自動検出
- 標準の assert 文が使用できる
- デコレータで依存性注入可能

## 検証その１

```py filename="Python"
# main.py
def add(a, b):
    return a + b

def validate_age(age):
    if age < 0:
        raise ValueError("年齢は0以上である必要があります")
    return age

# main_test.py
import pytest
from main import add, validate_age

def test_add():
    assert add(2, 3) == 4 #意図的に誤った値を設定する
    assert add(-1, 1) == 0

def test_validate_age():
    assert validate_age(25) == 25
    with pytest.raises(ValueError):
        validate_age(-5)
```

足し算する関数と年齢が 0 以上であることを確認する簡単な関数を作成しました。テストを実行するには、ファイル名と関数名に **\_test** を含める必要があります。

pytest コマンドだけで自動検出してテストしてくれます。
