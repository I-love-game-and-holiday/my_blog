**メソッド**は、オブジェクトに属している関数のことです。

普通の関数との違いは、「誰の機能か」がはっきりしている点です。

## 身近な例で理解する

スマホには「電話をかける」「写真を撮る」などの機能がありますよね。<br />
これらはスマホという「モノ」に属している機能です。

プログラミングでも同じで、「配列」というオブジェクトには「要素を追加する」「要素を削除する」などのメソッドがあります。

## 関数とメソッドの違い

<ContentTable
  headers={["種類", "呼び出し方", "例"]}
  rows={[
    ["関数", "そのまま呼ぶ", "alert('Hello')"],
    ["メソッド", "オブジェクト.メソッド名() で呼ぶ", "array.push(1)"],

/>

```js
// 関数：そのまま呼び出す
alert('こんにちは');
parseInt('123');

// メソッド：オブジェクトを通して呼び出す
const fruits = ['りんご', 'バナナ'];
fruits.push('みかん');  // 配列のメソッド

const message = 'Hello';
message.toUpperCase();  // 文字列のメソッド
```

メソッドは必ず `.`（ドット）の前にオブジェクトがあります。

## よく使うメソッドの例

### 配列のメソッド

```js
const numbers = [1, 2, 3];

numbers.push(4);      // 末尾に追加 → [1, 2, 3, 4]
numbers.pop();        // 末尾を削除 → [1, 2, 3]
numbers.includes(2);  // 含まれるか確認 → true
```

### 文字列のメソッド

```js
const text = '  Hello World  ';

text.trim();          // 前後の空白を削除 → 'Hello World'
text.toUpperCase();   // 大文字に変換 → '  HELLO WORLD  '
text.split(' ');      // 分割して配列に → ['', '', 'Hello', 'World', '', '']
```

### DOM要素のメソッド

```js
const button = document.getElementById('btn');

button.addEventListener('click', handleClick);  // イベント登録
button.remove();  // 要素を削除
```
