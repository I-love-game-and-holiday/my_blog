term: コミット

---

**コミット（Commit）**は、ファイルの変更を記録する操作です。「セーブポイント」のようなものと考えてください。

## コミットに含まれる情報

- **変更内容**: どのファイルがどう変わったか
- **作成者**: 誰がコミットしたか
- **日時**: いつコミットしたか
- **メッセージ**: 何を変更したかの説明

## コミットの作り方

```bash
# 変更をステージング
git add ファイル名

# コミットを作成
git commit -m "変更内容の説明"
```

## 良いコミットメッセージの例

- `ログイン機能を追加`
- `ボタンの色を青に変更`
- `バグ修正: ユーザー名が保存されない問題`
