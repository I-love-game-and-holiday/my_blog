**Git**は、プログラムのソースコードなどの変更履歴を記録・追跡するための**分散型バージョン管理システム**です。

## 主な特徴

- **変更履歴の記録**: いつ、誰が、何を変更したかを記録
- **過去の状態に戻せる**: 問題があれば以前のバージョンに戻せる
- **複数人での共同作業**: チームで同時に開発できる

## よく使うコマンド

```bash
git init      # リポジトリを初期化
git add       # 変更をステージング
git commit    # 変更を記録
git push      # リモートに送信
```
