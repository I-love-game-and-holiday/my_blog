**タイポ**（Typo）は、**タイプミス**や**誤字**を意味するスラングです。<br />
「Typographical error（印刷上の誤り）」の略語に由来します。


## プログラミングでのタイポ

プログラミングにおいて、タイポは非常に厄介なバグの原因となります。

```javascript
// 『message』という変数を宣言
const message = "Hello World";

// 『message』の中身を確認するコマンドを実行
console.log(mesage); // ←タイポしてる

// 『mesage』という変数は宣言していないので見つからずエラーになる
// ReferenceError: mesage is not defined
```
エディタを使うと比較的気付きやすいですが、<br />
ターミナルのように実行前にエラーを教えてくれない場所ではタイポの可能性が増えます。


## みんなタイポにハマる

初心者から上級者までみんなハマります。**いつも使ってるコマンドだから間違ってるわけない。**
この思い込みで不具合の原因を別の場所に求めだします。環境やソフトが変わったタイミングでエラーが
出始めたので設定が問題だと思ったら、単にタイポしてたということが結構あります。

不具合があったら、タイポの可能性を捨てないで、一旦確認しましょう。

<small>2日かけて不具合を調査した末、原因がタイポだったことがあります。恥ずかしい..</small>
