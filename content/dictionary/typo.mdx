**タイポ**（Typo）は、**タイプミス**や**誤字**を意味するスラングです。「Typographical error（印刷上の誤り）」の略語に由来します。

<small>ここに一言コメントを追加できます。</small>

## プログラミングでのタイポ

プログラミングにおいて、タイポは非常に厄介なバグの原因となります。

```javascript
// タイポの例
const message = "Hello World";
console.log(mesage); // ← "message" を "mesage" とタイポ
// ReferenceError: mesage is not defined
```
