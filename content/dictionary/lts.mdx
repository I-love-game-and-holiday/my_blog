**LTS**（Long Term Support）は、ライブラリ等の**長期サポート版**を指します。通常版より長い期間、セキュリティアップデートやバグ修正が提供されます。

## Node.jsのLTS例

```
Node.js 20 LTS  → 2026年4月までサポート
Node.js 22 LTS  → 2027年4月までサポート
```

## いつLTSを使うべき？

| シーン | 推奨バージョン |
|--------|----------------|
| 本番環境・仕事 | LTS版 |
| 学習・個人開発 | LTS版または最新版 |
| 新機能を試したい | 最新版（Current） |

## 補足

Node.js、Ubuntu、Javaなど多くのソフトウェアがLTS版を提供しています。特に理由がなければ**LTS版を選ぶのが安全**です。
