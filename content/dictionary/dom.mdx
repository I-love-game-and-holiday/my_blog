**DOM**（Document Object Model）は、HTMLをJavaScriptから操作するための仕組みです。

ブラウザがHTMLを読み込むと、その内容を「オブジェクト」として扱えるようにしてくれます。<br />
このオブジェクトを通じて、JavaScriptからページの内容を変更できます。

## 身近な例で理解する

HTMLを「家の設計図」だとすると、DOMは「実際に建てられた家」です。

## DOMでできること

JavaScriptでDOMを操作すると、ページを動的に変更できます。

<ContentTable
  headers={["操作", "例"]}
  rows={[
    ["要素を取得する", "document.getElementById('btn')"],
    ["テキストを変更する", "element.textContent = '新しいテキスト'"],
    ["要素を追加する", "parent.appendChild(newElement)"],
    ["要素を削除する", "element.remove()"],
    ["スタイルを変更する", "element.style.color = 'red'"],
  ]}
/>

```js
// ボタン要素を取得
const button = document.getElementById('my-button');

// テキストを変更
button.textContent = 'クリックしてね';

// クリックされたときの処理を追加
button.addEventListener('click', () => {
  alert('クリックされました！');
});
```

## DOM要素とは

「DOM要素」とは、HTMLの各パーツ（タグ）をJavaScriptで扱えるようにしたものです。

```html
<button id="my-button">送信</button>
```

このHTMLの `<button>` タグは、DOMでは「要素（Element）」というオブジェクトになります。<br />
このオブジェクトには、テキストを変える機能やクリックを検知する機能などが備わっています。
