**レスポンス**は、**サーバーからクライアント（ブラウザやアプリ）に返す「返事」** のことです。

クライアントがリクエストを送ると、サーバーは処理結果をレスポンスとして返します。

## レスポンスの構造

HTTPレスポンスは3つの部分で構成されています。

```
HTTP/1.1 200 OK                 ← ステータスライン
Content-Type: application/json  ← ヘッダー

{                               ← ボディ
  "id": 123,
  "name": "田中太郎"
}
```
