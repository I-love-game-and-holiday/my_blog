**HTTPメソッド**は、**サーバーに対して「どんな操作をしたいか」を伝えるもの**です。

同じURLでも、メソッドによって動作が変わります。

<ContentTable
  headers={["メソッド", "操作", "例"]}
  rows={[
    ["GET", "取得する", "ユーザー情報を取得"],
    ["POST", "作成する", "新しいユーザーを作成"],
    ["PUT", "更新する", "ユーザー情報を更新"],
    ["DELETE", "削除する", "ユーザーを削除"],
  ]}
/>

```
GET    /users/1   → ID:1のユーザーを取得
POST   /users     → 新しいユーザーを作成
PUT    /users/1   → ID:1のユーザーを更新
DELETE /users/1   → ID:1のユーザーを削除
```

HTTPメソッドはCRUD操作（Create, Read, Update, Delete）に対応しています。
