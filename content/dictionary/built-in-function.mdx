**組み込み関数**は、プログラミング言語にあらかじめ用意されている関数のことです。

自分で作らなくても、最初から使える便利な道具だと思ってください。

## 身近な例で理解する

スマホを買ったとき、最初から「電話」「カメラ」「時計」などのアプリが入っていますよね。<br />
プログラミング言語も同じで、最初から使える機能（関数）が用意されています。

JavaScriptには多くの組み込み関数があります。いくつか代表的なものを見てみましょう。

```js
// 組み込み関数の使用例
console.log("これは組み込み関数");  // コンソールに出力

const num = parseInt("123");  // 文字列を数値に変換
console.log(num + 1);  // 124
```

## メソッドと組み込み関数

`addEventListener()` のように、オブジェクトに対して使う関数は「メソッド」と呼ばれます。<br />
厳密には区別されますが、どちらも「言語が用意してくれた機能」という点では同じです。

```js
// 組み込み関数
console.log("Hello");

// メソッド（DOMオブジェクトの組み込み機能）
element.addEventListener('click', handleClick);
```

初心者のうちは「自分で定義していない関数 = 組み込み（または標準で用意されている）」と覚えておけば大丈夫です。

## なぜ組み込み関数が大切？

組み込み関数を使うことで、複雑な処理を一から書く必要がなくなります。

例えば `Math.random()` を使えば、乱数を生成する仕組みを自分で作る必要はありません。<br />
組み込み関数を知っているほど、効率よくコードが書けるようになります。
