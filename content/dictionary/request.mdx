**リクエスト**は、**クライアント（ブラウザやアプリ）からサーバーに送る「お願い」** のことです。

HTTP通信では、まずクライアントがリクエストを送り、サーバーがレスポンスを返すという流れでデータをやり取りします。

## リクエストの構造

HTTPリクエストは3つの部分で構成されています。

```
GET /users/123 HTTP/1.1         ← リクエストライン
Host: api.example.com           ← ヘッダー
Accept: application/json

{ "name": "田中" }              ← ボディ（あれば）
```
