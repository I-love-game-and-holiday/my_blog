---
term: リポジトリ
aliases: ["repository", "レポジトリ", "リポ", "repo"]
---

**リポジトリ（Repository）**は、プロジェクトのファイルと変更履歴を保存する場所です。

## 2種類のリポジトリ

### ローカルリポジトリ
自分のPC上にあるリポジトリ。`git init`で作成できます。

### リモートリポジトリ
GitHubやGitLabなどのサーバー上にあるリポジトリ。チームで共有するために使います。

## 作成方法

```bash
# 新しいリポジトリを作成
git init

# 既存のリポジトリをコピー
git clone https://github.com/user/repo.git
```
