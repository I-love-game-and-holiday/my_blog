---
term: ブランチ
aliases: ["branch", "ブランチ"]
---

**ブランチ（Branch）**は、開発の流れを分岐させる機能です。木の枝（branch）のように、本流から分かれて作業できます。

## なぜブランチを使う？

- **機能ごとに分けて開発**: 新機能を別ブランチで作成
- **本番環境を安全に保つ**: mainブランチを壊さずに作業
- **複数人で同時開発**: 各自が別ブランチで作業

## よく使うブランチ名

| ブランチ名 | 用途 |
|-----------|------|
| `main` | 本番用のメインブランチ |
| `develop` | 開発用のブランチ |
| `feature/xxx` | 新機能開発用 |
| `fix/xxx` | バグ修正用 |

## 基本操作

```bash
# ブランチを作成
git branch 新しいブランチ名

# ブランチを切り替え
git checkout ブランチ名

# 作成と切り替えを同時に
git checkout -b 新しいブランチ名
```
