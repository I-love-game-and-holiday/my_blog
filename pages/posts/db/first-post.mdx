# Next.js と Nextra でブログを始める

Next.js と nextra-theme-blog を使って、簡単に技術系ブログを構築することができます。

## 特徴

- **Markdown/MDX で記事を書ける**: シンプルな Markdown 記法で記事を作成できます
- **コードハイライト**: コードブロックが自動的にハイライトされます
- **ダークモード対応**: ダークモードとライトモードを切り替えられます
- **LaTeX 対応**: 数式を書くことができます

## 使い方

`pages/posts/`ディレクトリに`.mdx`または`.md`ファイルを作成するだけで、自動的にブログ記事として認識されます。

```typescript
// 例: pages/posts/my-post.mdx
---
title: '記事のタイトル'
date: '2025-01-03'
description: '記事の説明'
---

# 記事の内容
```

## まとめ

Next.js と nextra-theme-blog を使えば、開発者向けのブログを簡単に構築できます。ぜひ試してみてください！
